# Final Project - Emotion Detection Application

## Project Description
This is the Final Project for the IBM Python Web Development course. The project involves building an Emotion Detection application using Watson NLP, packaging it as a Python library, wrapping it in a Flask web application, and applying unit testing and static code analysis with Pylint.

## Features
- Emotion analysis returning scores for anger, disgust, fear, joy, and sadness.
- Identification of the dominant emotion.
- Robust handling for blank and invalid inputs (HTTP status 400).
- Fully tested with `unittest` and formatted following PEP 8 guidelines.
